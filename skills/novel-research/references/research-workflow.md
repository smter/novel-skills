# 调研工作流

## 概述

当你需要收集设定事实、领域真实性、风格参照或术语时，使用本文件。只有把调研结果转化为项目约束后，调研才算完成。

## 关键决策

- Default to web research unless the user explicitly refuses it.
- Keep verified facts, unresolved questions, and inferences clearly separated.
- Convert every useful source into writing constraints, not just saved links.
- Record uncertainty explicitly instead of hiding it in confident prose.

## 搜索策略

以下场景应进行联网调研：

- historical or period detail
- profession workflows
- geography, climate, or regional context
- cultural practices
- terminology and realism checks
- style reference verification when the user asks for grounded comparisons

如果用户禁止搜索：

- do not browse
- note uncertain claims as inferences
- record the missing verification in `10-research/references.md`

## 转化规则

每条有用发现都应转化为以下一种或多种内容：

- a setting constraint
- a terminology note
- a realism pitfall
- a taboo or continuity risk
- a style rule
- an open question that still needs resolution

## 反模式

- dropping a link list into `references.md` without interpretation
- mixing inference with verified facts in the same bullet
- treating genre familiarity as a substitute for verification

## 指引

- Read `file-contract.md` to see which files need which sections.
- Read `completion-gate.md` before ending the research phase.
