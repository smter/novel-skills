| 步骤 | 内容 | 目标文件 |

| char_step1 | 外显模块：面容/身体/声音/气味/服装 | 同上 |
| char_step2 | 内质模块：人格/驱动力/动机/世界观体系（含 MBTI/Enneagram） | 同上 |

另有「角色审查模块」：基于麦基《人物》的三阶段诊断流程（一致性→深度与维度→漏洞优化）。

## 拆分为子项目

建议分解为以下独立 spec，每个独立设计&实施：

1. **珠矶角色管线提取** — char_step0~7 + 角色审查 → `character-interview-guide.md` 增强
2. **珠矶世界观构建体系提取** — Task 2/4 + 地图模块 → `worldbuilding-guide.md`
3. **珠矶风格与叙事框架提取** — 风格复现宪章 + 文体学 + 叙事学 → 对应的 references 文件
4. **珠矶参考理论提炼** — 麦基三部曲 + 故事圈 → `references/theory/` 下的参考文件
5. **珠矶提示词工程方法论提取** — 思路梳理/自检/COT → SKILL.md 和 lint-contract 增强
