## 文件设计

### 产出 A：style-analysis-guide.md

**路径：** `skills/novel-research/references/style-analysis-guide.md`

**定位：** Agent 操作手册 — agent 在 novel-research Phase 4 撰写 `10-research/style-research.md` 时按步骤分析用户指定的风格参照，产出可执行的风格约束。也可供 novel-drafting Writer 子代理在起草时查阅风格规则。

**文件结构：**

```text
style-analysis-guide.md
├── 引言 — 使用方式 + 源 prompt 索引
├── 第一部分：文体分析流程（[134] 文体学构建）
│   ├── 阶段一：文体定位与功能分析
│   ├── 阶段二：语言特征解构（词汇/句法/修辞）
│   ├── 阶段三：作者本质分析（叙事风格/审美倾向）
│   └── 阶段四：复构与评估优化
├── 第二部分：风格复现宪章（[133] 风格复现宪章）
│   ├── 神层 — 核心法则（基调/气质/精神内核）
│   ├── 骨层 — 结构法则（叙事结构/节奏/章法）
│   ├── 皮层 — 语言积木（词汇/句式/修辞手法）
│   └── 肉层 — 风格展示（段落/场景/对话示例）
├── 第三部分：轻型文风（[84] 快速通道）
│   └── 简化流程：文体定位 → 文风要点 → 输出规则
└── 附录A：官能内容风格说明（[44] 条件性）
```

**各部分关系：** 文体分析流程（第一部分）用于分析源文本/风格参照；风格复现宪章（第二部分）是将分析结果转化为可执行风格法则的框架；轻型文风（第三部分）是对简单风格的快捷通道。

**各板块设计：**

#### 引言

使用方式 + 源 prompt 索引。说明此文件在何时使用（Phase 4 风格 research、Phase 5 自检风格一致性）。

#### 第一部分：文体分析流程（[134]）

阶段一：文体定位与功能分析
- 判断文体归属（小说/散文/诗歌/…需细化——如「中国科幻搞笑网络小说」「日式轻松校园恋爱轻小说」）
- 文体的核心功能与审美原则

阶段二：语言特征解构
- 词汇层次（常用词 vs 罕见词比例、术语密度、词汇新鲜度）
- 句法结构（句长分布、复杂句频率、主从句配比、句式变化频率）
- 修辞手法（使用频率最高的修辞类型、典型用法）

阶段三：作者本质分析
- 作者/风格的独特性（区别于同类作品的关键差异）
- 读者感观预期（读这种风格的人期待什么）

阶段四：复构与评估优化
- 产出风格模仿法则
- 评估模仿质量（与原风格对比、调整优化）

**产出格式：**
```markdown
### 文体分析结果
- **文体定位**：{细化文体描述}
- **语言特征**：{词汇/句法/修辞摘要}
- **作者本质**：{独特性和读者预期}
- **复构法则**：{可执行的风格模仿要点}
```

#### 第二部分：风格复现宪章（[133]）

四层框架，每层包含对应维度的分析和产出。

**神层 — 核心法则（不可变规则）**
- 故事的核心气质与精神内核
- 不可违背的基调和情感规则
- 例：「永远保持希望感，即使在最黑暗的段落」「叙述者始终保持幽默的旁观姿态」

**骨层 — 结构法则**
- 叙事结构偏好（线性/倒叙/多视角/插叙频率）
- 节奏特征（紧张→舒缓的交替模式、每章节的信息密度）
- 段落组织方式（长短交替等）

**皮层 — 语言积木**
- 高频词汇表、典型句式结构、修辞手法偏好
- 输出风格化的词汇/句式限制（如「避免使用四字成语」「多用短句和省略号」）
- 这些积木是"可替换"的，但替换后仍应保持风格一致

**肉层 — 风格展示**
- 经过风格约束后的实际文字示例
- 展示同一场景在风格约束下的写法

**产出格式（写入 `style-research.md`）：**
```markdown
## Style Research
### 神层（核心法则）
{2–5 条不可违背的风格规则}

### 骨层（结构法则）
{2–4 条叙事/节奏规则}

### 皮层（语言积木）
{词汇/句式/修辞约束}

### 肉层（风格展示）
{1–2 段风格化文字示例}
```

#### 第三部分：轻型文风（[84]）

简化版，当风格分析不需深度时使用：
- 文体定位 → 文风要点 → 输出规则
- 一句话文风描述 → 具体约束（词汇/句式/情感倾向）

**使用条件：** 用户未提供具体风格参照，仅描述了大致风格方向（如「轻松搞笑」）时使用。

#### 附录A：官能内容风格说明（[44]）

用户声明官能/色情内容时启用：
- 色情内容的正向化处理（非伤害性、愉悦性、开放性）
- 风格化规则（参考日本里番/本子/色情小说的审美取向）
- 使用条件：仅当用户明确声明官能创作时生效

### 产出 B：narrative-structure-guide.md

**路径：** `skills/novel-research/references/narrative-structure-guide.md`

**定位：** Agent 操作手册 — agent 在 novel-research Phase 4 设计故事结构时使用。叙事框架设计 → 叙事网络梳理 → 章节细化，串联到 novel-drafting 的 chapter plan。

**文件结构：**

```text
narrative-structure-guide.md
├── 引言 — 使用方式 + 源 prompt 索引
├── 第一部分：叙事框架设计（[135] 叙事学构建）
│   ├── 身份层 — 预设作者与语境
│   ├── 故事层 — 情节结构与叙事序列
│   ├── 话语层 — 叙述视角与时间处理
│   └── 读者层 — 预期读者反应与解读
├── 第二部分：叙事网络梳理（[138] 适配线性）
│   ├── 剧情纲目 — 章节概览与起承转合
│   ├── 叙事流 — 章节之间因果链与情感弧线
│   └── 线索管理 — 伏笔/呼应/揭示节奏
└── 第三部分：章节细化（[139] 适配线性）
    └── 逐章节深度设计 → 产出 chapter-plan.md 条目
```

**各部分关系：** 叙事框架设计（第一部分）建立整个故事的叙事原则；叙事网络梳理（第二部分）将原则落实到章节布局；章节细化（第三部分）产出每个章节的详细信息，可直接写入 chapter-plan.md。

#### 引言

使用方式 + 源 prompt 索引。说明此文件在何时使用，以及产出与 `chapter-plan.md` 的对应关系。

#### 第一部分：叙事框架设计（[135]）

**身份层 — 预设作者与语境**
- 预设作者（叙事声音的人格面具、知识范围、价值立场、情感倾向）
- 历史/文化语境（故事发生的时代背景的叙事含义）

**故事层 — 情节结构与叙事序列**
- 情节结构（线性/非线性、多线并进/单线推进、是否有嵌套叙事）
- 叙事序列（事件因果关系、时序安排、幕结构/三幕/五幕/哈蒙故事圈）

**话语层 — 叙述视角与时间处理**
- 叙述视角（第一人称/第三人称有限/全知/多视角切换规则）
- 时间处理（顺叙/倒叙/插叙/预叙/时空跳跃的频率和规则）
- 叙述距离（贴近人物内心 vs 上帝视角叙事）

**读者层 — 预期读者反应与解读**
- 预期读者的阅读体验（信息不对称、悬念设计、情感操控的预期效果）
- 空白与填充（哪些信息留给读者推断，哪些直接展示）

**产出格式（写入 `plot-outline.md` 的叙事约束部分）：**
```markdown
### 叙事框架
- **身份层**：{预设作者特征}
- **故事层**：{情节结构/叙事序列描述}
- **话语层**：{视角/时间/距离规则}
- **读者层**：{预期读者体验}
```

#### 第二部分：叙事网络梳理（[138] 适配线性）

适配为线性章节叙事网络：

**剧情纲目**
- 章节列表（每一章一句话概括剧情 + 标注起承转合的环节）
- 章节间的因果链（前一章如何引出后一章）

**叙事流**
- 情感弧线（每章的情感基调 → 全书的情感曲线）
- 紧张度曲线（紧张→缓解的交替节奏）

**线索管理**
- 伏笔设置时间点（哪一章埋下伏笔？）
- 呼应/揭示时间点（哪一章收束？）
- 与 `foreshadowing.md` 中已有的伏笔清单对照，确保不遗漏

**产出格式（更新 `plot-outline.md`）：**
```markdown
### 叙事网络
- **章节概览**：{每章 1 句摘要 + 起承转合位置}
- **情感弧线**：{各章情感基调}
- **线索管理**：{伏笔→揭示对应表}
```

#### 第三部分：章节细化（[139] 适配线性）

对每个章节做深度设计：

- 本章目标（推进哪条线索/塑造哪个角色/揭示什么信息）
- 出场角色（与角色卡中的角色列表对齐）
- 时空起止（发生在哪里、跨越多少时间）
- 关键场景（2–5 个场景，每个场景一句话概括）
- 与前后章的连接（承接前章的哪件事、为后章埋什么线）
- 预期字数（与 chapter-plan 中的字数目标对齐）

**产出格式（写入 `30-draft/chapter-plan.md` 的对应章节条目）：**
```markdown
### Chapter-XX
- **目标**：{}
- **出场角色**：{}
- **时空**：{}
- **关键场景**：{}
- **衔接**：{前→→后}
- **预期字数**：{}
```
